# Product Requirements

## Problem
Users often have databases but need SQL knowledge to extract information. knowUrDB allows users to interact with databases using natural language.

## Target Users
Initially:
- Developers
- Students
- Analysts
- Technical teams
- Database users who understand business questions but may not know SQL

## MVP Capabilities
The future MVP must support:
- Built-in demo database.
- SQLite database upload.
- Database validation.
- Schema inspection.
- Natural-language question input.
- Gemini-powered SQL generation.
- SQL validation.
- Read-only SQL execution.
- Result table.
- Generated SQL display.
- Concise AI explanation.
- Error handling.

## Future Capabilities
- Conversational queries
- Query history
- Saved queries
- Charts
- Automatic insights
- Schema retrieval for large databases
- Multiple database engines
- Authentication
- Multi-user support
- Usage analytics
- Query performance monitoring
- Evaluation framework
- Production deployment
