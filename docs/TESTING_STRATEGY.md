# Testing Strategy

## Unit Tests
Test isolated backend/frontend functionality.

## Integration Tests
Test: Frontend → API → database.

## AI Tests
Test natural-language questions against known schemas.

## SQL Security Tests
Test malicious SQL generation and ensure rejection.

## Evaluation Benchmark
Create the plan for a future benchmark containing questions and expected results. Track metrics such as:
- SQL validity
- SQL execution success
- Result correctness
- Latency
- Failure rate

The final project should eventually report measurable Text-to-SQL performance.
