# Testing Strategy

## Testing Layers
The project will implement the following future testing layers:
1. Unit testing
2. Integration testing
3. API testing
4. Database testing
5. SQL validation/security testing
6. AI/Text-to-SQL testing
7. End-to-end testing
8. Performance testing
9. Regression testing
10. Evaluation benchmark

## Evaluation Benchmark
The future Text-to-SQL evaluation framework will use a controlled benchmark containing natural-language questions, database schemas, expected SQL where appropriate, and expected results.

It will track and report the following metrics:
- SQL validity rate
- SQL execution success rate
- result correctness
- exact result accuracy where applicable
- semantic/result accuracy where exact comparison is insufficient
- average latency
- p95 latency
- failure rate
- AI retry/correction rate

*Note: Do not implement the benchmark yet. The final project should eventually report measurable Text-to-SQL performance.*
